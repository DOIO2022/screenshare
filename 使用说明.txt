LanShare — 局域网远程观看与控制
================================

【重要：使用本程序不用装任何依赖】
  · 不需要安装 Python
  · 不需要 pip install
  · 不需要 requirements.txt
  · 双击 LanShare.exe 即可（绿色软件）

  以下两种方式任选一种拷贝到 Windows 电脑：

  方式 A — 文件夹版（推荐，启动快）
    复制整个「LanShare-win32-x64」文件夹，双击其中的 LanShare.exe
    必须整夹拷贝（含 _internal 等），不要只拷一个 exe

  方式 B — 单文件版
    只复制 dist\LanShare.exe（可选带上本说明）
    首次打开可能稍慢（解压到临时目录），杀毒软件有时会误报，可添加信任

【被控电脑】
  ·「开始共享」→ 防火墙选「专用网络」允许
  · 可选密码；取消「允许远程键鼠」则仅观看

【控制电脑】
  · 左侧选主机「连接选中」，或手动输入 192.168.x.x:8765
  · 连接后先点一下右侧画面再键鼠操作；F11 全屏

【开机自启】
  ·「开机自启」：登录后自动打开程序
  ·「启动后自动开始共享」：打开后自动可被局域网连接

【只有「打包的人」才需要装 Python】
  若你拿到的是源码而不是 exe，请在 Windows 上运行 build.bat 或 build-onefile.bat
  生成上述绿色版后再发给其他人使用。
